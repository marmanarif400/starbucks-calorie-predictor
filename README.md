
# Starbucks Calorie Prediction

A machine learning project that uses a Decision Tree Regressor
to estimate calories in Starbucks beverages.

## Model
- Algorithm: Decision Tree Regression
- File: `starbucks_decision_tree.pkl`
- Framework: Scikit-learn

## Project Goals
- Analyze Starbucks beverage nutrition data
- Explore calorie distributions
- Train a Decision Tree model
- Predict calories using available beverage features

## Current Status
The trained model has been uploaded to this repository.

The Python application and instructions for making predictions
will be added separately.

## Important
Predictions depend on the dataset and input features.
They should not be treated as official nutrition information.
